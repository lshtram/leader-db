# 2022 Top-20 Ruler Scores

This static viewer presents eight comparative chapter scores for each of twenty 2022
rulers. Selecting a score opens the complete chapter record: ten evidence lenses,
compact cited evidence, judge confidence and plausible range, ruler attribution,
comparative anchors, and the score rationale.

Serve locally from the repository root:

```bash
python -m http.server 19000 --directory docs/client-results/2022-top20
```

Then open `http://127.0.0.1:19000/`. `data.json` is deterministically generated by
`scripts/build_conversational_results_viewer.py`. The viewer does not contain or compare
client scores for 2022. Five chapter cells remain unscored where evidence was
insufficient; the viewer displays those cells as `No score`.

The release uses the audited chapter judgments from the completed 2022 hybrid run,
including the corrected 8B judgment batch. The viewer includes the exact normative
attribution record in `attributions.md`.
