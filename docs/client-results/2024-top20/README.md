# 2024 Top-20 Ruler Scores

This static viewer presents eight comparative chapter scores for each of twenty 2024
rulers. Selecting a score opens the complete chapter record: ten evidence lenses,
compact cited evidence, judge confidence and plausible range, ruler attribution,
comparative anchors, and the self-contained score rationale.

Serve locally from the repository root:

```bash
python -m http.server 19000 --directory docs/client-results/2024-top20
```

Then open `http://127.0.0.1:19000/`. `data.json` is deterministically generated by
`scripts/build_conversational_results_viewer.py`. The viewer does not contain or compare
client scores for 2024.

Chapters 1B, 3B, and 7B are selected from their v4 absolute-scale, scope-filtered
judgment batches. Original and rejected correction attempts remain preserved in the
research workspace. Chapters 2B, 5B, and 6B passed provisionally; 4B and 8B retain their
original scores with documented cautions. The viewer includes the exact normative
attribution record in `attributions.md`.
